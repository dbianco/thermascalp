# Hardware

Planned contents (not yet started):

```text
hardware/
  helmet/       printable TPU shell, manifolds, channel layouts (STEP + STL)
  cart/         frame, tank mounting, electronics bay
  electronics/  schematics and PCB or perfboard layouts
  test-rigs/    thermal dummy head, flow and uniformity test coupons
```

Source files should be in open formats (FreeCAD, STEP, KiCad), with exported STL or PDF files alongside. See the
[architecture overview](../docs/architecture/overview.md) and the [roadmap](../ROADMAP.md).
